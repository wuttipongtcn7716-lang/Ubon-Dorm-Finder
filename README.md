# Dormie UBU - ระบบค้นหาหอพักสีขาว & GPS นำทาง มหาวิทยาลัยอุบลราชธานี

เว็บแอปพลิเคชันสำหรับนักศึกษาเพื่อค้นหาและตรวจสอบมาตรฐาน "หอพักสีขาว" ในพื้นที่รอบมหาวิทยาลัยอุบลราชธานี พร้อมแผนที่แบบ Interactive ระบบกรองข้อมูลละเอียด และระบบ GPS นำทางแบบเรียลไทม์

---

## ฟีเจอร์หลัก (Key Features)

1. **ระบบค้นหาและตัวกรองหอพัก (Advanced Filter & Search)**:
   - กรองตามโซนรอบ ม.อุบลฯ (เช่น โซนบ้านแมด, โซนบ้านศรีไคออก, ประตู 1)
   - กรองเฉพาะ **หอพักสีขาว** ที่ผ่านการประเมินมาตรฐานปี 2569 (กล้อง CCTV, คีย์การ์ด, รปภ.)
   - กรองตามช่วงราคา, ประเภทห้อง (แอร์/พัดลม), ประเภทผู้พัก (ชาย/หญิง/รวม)
   - กรองตามความเสี่ยงน้ำท่วมขังช่วงหน้าฝน, การเลี้ยงสัตว์, และการประกอบอาหาร
2. **แผนที่แบบ Interactive (Interactive Map Explorer)**:
   - ปักหมุดหอพักทั้งหมด 60 แห่งรอบมหาวิทยาลัย
   - แยกสัญลักษณ์หอพักสีขาว (🛡️ สีเขียว) และหอพักทั่วไป (🏠 สีเทาเข้ม) ชัดเจน
   - สลับมุมมองได้ทั้งแบบ **แบ่งหน้าจอ (Split View)**, **การ์ด (Grid View)**, และ **แผนที่เต็มจอ (Map View)**
3. **หน้าโปรไฟล์หอพัก (Dormitory Profile)**:
   - แสดงรายละเอียดราคา ค่าน้ำ ค่าไฟ เงินมัดจำ สัญญาขั้นต่ำ
   - แสดงรายละเอียดผลประเมินมาตรฐานหอพักสีขาวของ ม.อุบลฯ
   - ปุ่มโทรออกหาเจ้าของหอ, Line ID, Facebook
   - ปุ่มหลัก Call To Action: **"เริ่มนำทาง (Start Navigation)"**
4. **โหมดแผนที่นำทาง GPS (Real-Time GPS Route & Navigation)**:
   - ขอพิกัด GPS ปัจจุบันของผู้ใช้ (Point A)
   - คำนวณระยะทางและเวลาเดินทางไปยังหอพัก (Point B)
   - สลับรูปแบบการเดินทาง: รถยนต์, รถมอเตอร์ไซค์, เดินเท้า
   - ปุ่มกดเปิดต่อในแอป Google Maps บนมือถือเพื่อรับเสียงนำทางแบบเลี้ยวต่อเลี้ยว (Turn-by-Turn Voice Navigation)

## โครงสร้างฐานข้อมูล (Database Schema - Chen Model)

ไฟล์ Schema และ Data Seed อยู่ในโฟลเดอร์ `db/`:
- `db/schema.sql` : โครงสร้างตาราง MySQL ตามรูปแบบ Chen's ER Model
  - `zones`: โซนพื้นที่รอบมหาวิทยาลัย
  - `dormitories`: ข้อมูลหลักหอพักและพิกัด Lat/Lng
  - `white_dorm_evaluations`: ผลการประเมินมาตรฐานหอพักสีขาว
  - `dorm_facilities`: สิ่งอำนวยความสะดวกและความปลอดภัย
  - `dorm_surroundings`: สภาพแวดล้อม สถานที่ใกล้เคียง และความเสี่ยงน้ำท่วม
- `db/seed.sql` : ข้อมูลตั้งต้นหอพักจริง 60 แห่งรอบ ม.อุบลฯ พร้อม Import เข้า MySQL

## วิธีการรันโปรเจกต์ (How to Run)

### 1. รันโหมด Development (เปิดทดสอบทันที)
ดับเบิลคลิกไฟล์ **`dev.bat`** หรือเปิด PowerShell แล้วพิมพ์:
```powershell
.\dev.bat
```
จากนั้นเปิดเบราว์เซอร์ไปที่: **http://localhost:3000**

### 2. การตั้งค่า Google Maps API (Optional)
หากต้องการใช้งาน Google Maps API Key ของตนเอง ให้เปิดไฟล์ `.env.local` แล้วใส่ค่า Key:
```env
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your_google_maps_api_key_here
```
*(หากยังไม่ได้ใส่ Key ระบบจะใช้แผนที่ OpenStreetMap / Leaflet และ Google Directions Fallback ให้โดยอัตโนมัติ 100%)*
