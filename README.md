# Dormie UBU - ระบบค้นหาและนำทางหอพักเครือข่าย ม.อุบลฯ

## ♿ Accessibility & Heading Hierarchy (M-02 Compliance)
โครงการ **Dormie UBU** ได้รับการออกแบบและปรับปรุงโครงสร้าง Semantic HTML ให้สอดคล้องกับเกณฑ์การเข้าถึงเว็บไซต์ (Web Accessibility) โดยเฉพาะข้อ **M-02**:

* **Heading Structure:**
  * **`<h1>`**: ใช้สำหรับหัวข้อหลักประจำหน้า (Banner Title) เพียง 1 ตำแหน่ง คือ *"ค้นหาหอพัก ม.อุบลฯ พร้อมระบบนำทาง"*
  * **`<h2>`**: ใช้สำหรับหัวข้อแบ่ง Section หลักของเนื้อหา เช่น *"พบหอพักทั้งหมด 60 แห่ง"*
  * **`<h3>`**: ใช้สำหรับชื่อหอพักทั้ง 60 รายการในการ์ดแสดงผล เพื่อสร้างลำดับชั้น Heading Outline (`<h1>` $\rightarrow$ `<h2>` $\rightarrow$ `<h3>`) ให้ถูกต้องสมบูรณ์
  
* **Testing & Evaluation:**
  * ผ่านการตรวจสอบและวัดผลด้าน Accessibility ด้วยเครื่องมือมาตรฐานอย่าง **Lighthouse** และ **axe DevTools** เพื่อลดข้อผิดพลาดทางเทคนิคและรองรับผู้ใช้งานทุกกลุ่ม
