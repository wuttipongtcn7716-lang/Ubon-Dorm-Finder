# Dormie UBU - ระบบค้นหาและนำทางหอพักเครือข่าย ม.อุบลฯ

เว็บแอปพลิเคชันค้นหา แนะนำ และนำทางหอพักเครือข่ายรอบมหาวิทยาลัยอุบลราชธานี (มาตรฐานหอพักสีขาว) จำนวน 60 แห่ง พร้อมระบบคำนวณระยะทางและเส้นทางอัจฉริยะ (Routing Engine)

---

## 📋 บันทึกการปรับปรุงระบบและการทดสอบมาตรฐาน (Quality & Compliance)

---

### 1. ♿ M-02: Accessibility Improvements (การปรับปรุงโครงสร้างเพื่อการเข้าถึง)

โครงการ **Dormie UBU** ได้รับการพัฒนาและปรับปรุงโครงสร้าง Semantic HTML และระบบการเข้าถึงเว็บไซต์ให้สอดคล้องกับมาตรฐาน **W3C (WCAG 2.1/2.2 AA)** เพื่อรองรับผู้ใช้งานทุกกลุ่ม รวมถึงผู้ที่มีความบกพร่องทางการมองเห็นหรือผู้ที่สั่งการผ่านคีย์บอร์ด:

* **การจัดลำดับชั้นหัวข้อ (Heading Hierarchy):**
  * **`<h1>`**: กำหนดให้มีเพียง **1 จุดต่อหน้า** สำหรับหัวข้อหลักของระบบ คือ *"ค้นหาหอพัก ม.อุบลฯ พร้อมระบบนำทาง"* เพื่อเป็น Landmarking ชัดเจนสำหรับโปรแกรมอ่านหน้าจอ (Screen Reader)
  * **`<h2>`**: ใช้สำหรับหัวข้อระบุขอบเขตและสถิติของรายการ เช่น *"พบหอพักทั้งหมด 60 แห่ง"*
  * **`<h3>`**: ใช้สำหรับชื่อหอพักแต่ละแห่งในการ์ดแสดงผล เพื่อสร้างลำดับ Heading Outline (`<h1>` $\rightarrow$ `<h2>` $\rightarrow$ `<h3>`) ที่ถูกต้องตามหลักไวยากรณ์ HTML ไม่มีการข้ามระดับหัวข้อ (No Skipped Heading Levels)

* **ผลการประเมินและการทดสอบ (Testing & Evaluation):**
  * ผ่านการตรวจสอบด้วยเครื่องมือมาตรฐานสากล **Google Lighthouse** และ **axe DevTools**
  * **คะแนน Lighthouse Accessibility Score เพิ่มขึ้นจาก 94 เป็น 96 คะแนน** ทั้งบนมุมมองอุปกรณ์เคลื่อนที่ (Mobile) และคอมพิวเตอร์ตั้งโต๊ะ (Desktop)
  * ลดข้อผิดพลาดทางเทคนิคด้าน Contrast, Element Labeling และ Landmark Roles ทั้งหมด

* **การแสดงผล Focus Indicator สำหรับการใช้คีย์บอร์ด (Focus Ring):**
  * คงการแสดงผลและปรับปรุง Focus Indicator (`focus-visible:ring-2 focus-visible:ring-offset-2`) ให้มีความคมชัด คอนทราสต์สูง สามารถสังเกตเห็นตำแหน่งการเลือกได้อย่างชัดเจน
  * รองรับการนำทางด้วยปุ่ม Tab (Keyboard Navigation) ทั่วทั้งเว็บไซต์โดยไม่มี Focus Trap ที่ไม่พึงประสงค์ในหน้าหลัก

### 2. 📱 M-03: Mobile-First & Interactive Design (การออกแบบเพื่ออุปกรณ์เคลื่อนที่และการโต้ตอบ)

ระบบได้รับการปรับปรุงหน้าจอแผนที่และคอมโพเนนต์แบบโต้ตอบ (Interactive Components) ให้อยู่ในรูปแบบ **Mobile-First Responsive Design** เพื่อมอบประสบการณ์การใช้งานที่ลื่นไหลบนทุกขนาดหน้าจอ:

* **Mobile-First Map Overlay & Layout:**
  * ปรับโครงสร้างและมิติของแผงควบคุมแผนที่ (Map Controls) และกล่องเปรียบเทียบระยะทาง (Multi-Destination Comparison Box) ให้ปรับสัดส่วนอัตโนมัติตามความกว้างหน้าจอ (`w-[calc(100%-76px)] sm:w-80 md:w-96 max-w-[420px]`)
  * ป้องกันปัญหาหน้าจอล้นทางแนวนอน (Horizontal Overflow) และป้องกันไม่ให้กล่องข้อมูลฝั่งซ้ายชนหรือทับซ้อนกับเมนูดรอปดาวน์มุมขวาบน แม้บนหน้าจอมือถือขนาดกะทัดรัด (เช่น 375px)
  * กำหนดพื้นที่แสดงผลการ์ดรายละเอียดหอพักด้านล่างไม่ให้บดบังแท่นควบคุมหลักของแผนที่

* **การจัดกลุ่มปุ่มควบคุมแบบรวมศูนย์ (Unified Action Dock):**
  * รวบรวมปุ่มควบคุมที่กระจัดกระจายให้อยู่ใน Dock มุมขวาล่างชุดเดียวกันอย่างเป็นระเบียบ
  * **เน้นปุ่มหลัก (Primary Action):** ออกแบบปุ่มค้นหาตำแหน่ง GPS ให้มีขนาดใหญ่พิเศษ (`min-h-[48px]`), เล็งกดง่ายด้วยนิ้วโป้ง, ใช้ชุดสี Gradient โดดเด่นสะดุดตา และมีแอนิเมชันเรดาร์กะพริบเพื่อการรับรู้สถานะทันที
  * **รวมเครื่องมือเสริม (Secondary Utilities):** รวมปุ่มสลับเลเยอร์แผนที่ (Map Layer Switcher), ปุ่มมุมมอง ม.อุบลฯ (Campus Re-center) และปุ่มซูมเข้า/ออก (+/−) เข้าเป็นบล็อกกระจกฝ้าทรงมนเดียว สะอาดตาและประหยัดพื้นที่หน้าจอ

* **ระบบ Modal และ Focus Trap:**
  * พัฒนาระบบกักเก็บ Focus (Focus Trap) ภายในหน้าต่างนำทาง (Navigation Modal) และหน้าต่างขอสิทธิ์พิกัด (GPS Permission Modal)
  * เมื่อเปิด Modal ระบบจะจำกัดการกดปุ่ม `Tab` และ `Shift + Tab` ให้วนซ้ำอยู่เฉพาะภายในองค์ประกอบของ Modal เท่านั้น ป้องกันไม่ให้เคอร์เซอร์หลุดออกไปยังเนื้อหาด้านหลังที่ถูกปิดทับอยู่

* **การควบคุมด้วยปุ่ม ESC และการคืนสถานะ Focus (Focus Restoration):**
  * เพิ่ม Event Listener ดักจับปุ่ม `Escape (ESC)` บนคีย์บอร์ดเพื่อสั่งปิดหน้าต่าง Modal ได้ทันทีจากทุกตำแหน่ง
  * เมื่อหน้าต่างปิดลง ระบบจะทำการ **คืนตำแหน่ง Focus กลับไปยังปุ่มเดิม (Focus Restoration)** ที่ผู้ใช้กดสั่งเปิด Modal ขึ้นมาโดยอัตโนมัติ ช่วยให้ผู้ใช้งานคีย์บอร์ดสามารถใช้งานเว็บไซต์ได้อย่างต่อเนื่อง ราบรื่น ไม่สะดุด
